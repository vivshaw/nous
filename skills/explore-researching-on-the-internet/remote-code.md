# Remote Code Research

Use this procedure when documentation does not answer how an external project actually behaves.

1. Find the official repository and its default or relevant release branch.
2. Clone or refresh a shallow copy in a stable temporary cache outside the active project.
3. Record the full commit SHA.
4. Search and read the source implementation using available repository tools.
5. Return a direct answer with `path:line` evidence from the cloned revision.

Do not answer from memory when the question requires current implementation details. Do not edit the external repository or write research files into the active project.
